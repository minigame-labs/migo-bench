# Security Policy

[English](SECURITY.md) | [中文](SECURITY.zh-CN.md)

## Reporting a Vulnerability

Please report security vulnerabilities to **security@minigame-labs.com** rather than opening a
public GitHub issue.

Include what you can: affected file/version, steps to reproduce, and potential impact. We aim to
acknowledge reports within 2 business days and will follow up as we investigate and address the
issue.

## Scope

This repository is a benchmarking harness (Migo vs. Android System WebView) and does not ship
runtime code. For vulnerabilities in the Migo runtime itself, the same address
(security@minigame-labs.com) applies.
